# План (ШАГ 0) — course-site-launch

> Детальный план под запуск публичного сайта-курса. Работаем строго по нему.

## Подход
Инфраструктурная задача (не piece). Lifecycle адаптируем: BRIEF → BLUEPRINT → **ROAST плана** →
**USER GATE** → инкрементальная сборка (скелет + 1 лекция proof) → гейт → масштабирование.
Три направления = три issue под зонтичным epic. Развязка фаз (A статик / B инфра / C охват) —
главный приём снижения риска. Генератор — один детерминированный скрипт, не фан-аут агентов.
Критика: independent-роаст плана на over-engineering и непроверенные зависимости ДО реализации.

## Делегирование
- **Роаст плана** (independent-агент) — objective: найти over-engineering, непроверенные зависимости
  (CF Pages/Vultr доступ, poppler, git-бლоат, i18n-без-EN), владельцев файлов, дыры изоляции.
  Not-your-job: не переписывать план, не менять зафиксированный стек. Output: SHIP/REVISE/HOLD + находки.
- (Позже, после гейта) перевод EN — субагенты, лекция-за-лекцией.
