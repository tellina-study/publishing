# Brief: публичный сайт-курс «AI-usage-lessons»

## Постановка (от владельца)
Опубликовать лекции курса в открытом доступе (RU + EN), чтобы:
1. можно было **хвастаться и пиарить личный бренд**;
2. **собирать обратную связь/отзывы**;
3. привлекать **органический SEO-трафик**;
4. опционально — **делиться со студентами**;
5. очень желательно — **статистика просмотров и ГЛУБИНЫ чтения** (scroll-события).

Бюджет: **бесплатно или ≤ $10/мес**. Видео НЕ делаем. Публикуем **слайды + комментарии** к ним;
главы (chapter) — опционально позже.

## Зафиксированный стек (согласован, не пересматривать без команды владельца)
- **Генератор:** MkDocs Material (структура «курс», markdown-native; i18n через `mkdocs-static-i18n` + hreflang).
- **Хостинг:** Cloudflare Pages (git push → авто-деплой, бесплатно, CDN).
- **Аналитика:** Umami, self-hosted на Vultr VM владельца (просмотры + custom scroll-события = глубина чтения).
- **Комментарии:** Remark42, self-hosted на том же Vultr (аноним/соц-логин, без обязательного GitHub) + реакции 👍/👎 + RSS.
- **Охват (позже):** синдикация топ-лекций на Habr (RU) / dev.to (EN) с canonical + SpeakerDeck для колод.

## Исходный контент (в ДРУГОМ репозитории)
`/home/harness/harness-projects/256/lessons-3bb49d40/library/lectures/lec-NN/` — **16 лекций**

(субагенты-переводчики, лекция-за-лекцией; уточнение владельца), НЕ внешняя задача. Не блокирует запуск.

### Разведка изменила две «открытые» вводные (решено реальностью, не вкусом)
- ❌ **`rendered/lec-NN-notes.pdf` НЕ существует** ни в одной из 16 лекций. → Источник комментариев
  может быть **только `speech.md`**, фрагментами по слайдам. Вопрос «speech vs notes.pdf» снят.
- ✅ **`speech.md` чисто маппится на слайды:** каждый слайд — заголовок `## [sNN · …]`, число совпадает
  со `slides_covered` во frontmatter. Парсинг детерминированный.
- ⚠️ **Slide-ID не последовательны** (s01, s00a, s00b, s02a, s05c…). Маппинг «страница PDF → slide-id»
  идёт **только через порядок в `deck.yaml`**, не через нумерацию.
- ⚠️ **`pdftoppm`/poppler НЕ установлены** — нужны и локально (генерация), и в среде сборки.
- ⚠️ **`speech.md` status: draft** — публикуем черновой контент публично; нужен явный гейт владельца.

## DO NOT
- Не строить всё сразу — сначала скелет + 1 лекция на превью под гейт владельца.
- Не публиковать наружу (живой домен/паблик-статус) без явного гейта.
- Не блокировать запуск сайта на self-hosted инфре (Vultr/Umami/Remark42) — развязать фазы.
- Не тащить исходные PDF в publishing-репо; коммитить только **производные** PNG + сгенерированный md.
- Не делать русский «героем» — RU-first ≠ русо-центризм (owner-taste: нейтральность к аудитории).
- Не переусложнять генератор: один детерминированный `sync_lectures.py`, не пайплайн из агентов.
