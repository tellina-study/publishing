# Каналы публикаций

Раздел про **направления публикаций**: технические и стилистические особенности каждого
канала. Один файл на канал. Пишем канонический материал один раз, потом деривируем под каждый
канал по его файлу.

Правило вкуса LinkedIn/блога/ТГ — производная от `notes/owner-taste.md` (база вкуса Макса);
здесь — прикладная выжимка *под конкретный канал* + техника (форматы, лимиты, пайплайн).
Держим как **живое тело**: свежие наблюдения — в «Лог» внизу каждого файла, периодически вносим
в тело. Когда Макс реагирует на пост в канале — фиксируем в тот же ход (правило зеркала).

| Канал | Файл | Форма | Статус знаний |
|---|---|---|---|
| **LinkedIn** | [`linkedin.md`](linkedin.md) | Проф. пост 150–500 слов, инсайт-хук к статье | Полно (правки Макса по опубликованному) |
| **Блог tellian.io** | [`blog.md`](blog.md) | Лонгрид 800–2500 слов, канонический дом | Пайплайн построен (wp_publish.py) |
| **Telegram** | [`telegram.md`](telegram.md) | Короткий пост/тред 100–600 слов | Форма ясна, стиль-специфика копится |
| _(новый канал)_ | [`_template.md`](_template.md) | — | копировать шаблон |

Каждый файл держит два слоя: **Техника** (формат, лимиты, механика/пайплайн публикации) и
**Стиль** (голос, хук, структура, длина, do/don't под этот канал).
