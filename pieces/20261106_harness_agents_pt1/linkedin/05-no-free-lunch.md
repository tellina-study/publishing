**We ran 54 tests across 3 AI coding agents, tracking both token cost and a quality rubric. No agent won on both at once.**

Hermes was the cheapest by tokens — and scored the lowest on quality where quality could be measured at all. dsh scored the highest on quality — but wasn't the cheapest. Claude Code was the most expensive — at middling quality.

Cheapest and best don't point at the same agent. Neither do most-expensive and worst.

If you're picking an agent off one headline number — price per token, or a single benchmark score — you're picking half the picture.

This was the closing chart of a 5-part look at the same dataset: quality that never moved, run-to-run noise bigger than the effect we were testing, a harness switch that helped one agent and hurt another, and a "cheaper model" that saved 9× for one agent and 56× for another.

Which of these would you want checked before picking an agent for your own stack?
