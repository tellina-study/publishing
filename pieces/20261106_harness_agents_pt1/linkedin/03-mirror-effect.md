**Same switch. Same task. One agent's token spend went up 333%. Another's dropped 74%. Both got the same answer wrong.**

We flipped the exact same "harness" (rules, tools, memory) on for two different coding agents, on the same task — a PR review with an independently pre-written answer key. Claude Code's cost quadrupled. Hermes's cost dropped to a quarter. Neither agent found the actual defects, with the harness or without it — 0 out of 4 either way.

Tokens moved in opposite directions. Correctness didn't move at all.

The same set of rules doesn't land the same way twice. Tune a harness for one agent, and it's a tune for that agent's character — not a setup that travels to the next one.

Has switching agents ever flipped a setup that "just worked" for you?
