**One AI coding agent changed zero files on a task — with a "harness" switched on, and with it switched off. Switching the harness on still made that same zero-result attempt cost roughly four times more.**

Three coding agents ran the same task on the same model, each one twice — once with a harness (a set of rules, tools and memory wrapped around the agent) on, once with it off. Hermes didn't touch a single line of code in either run. Its score was zero both times. But turning the harness on made that same zero-result attempt cost roughly 4× more — the agent spent extra effort re-reading the requirements and checking against a checklist, without any of it turning into an actual edit.

Effort and outcome aren't the same thing. Two other agents made at least partial progress on the same task, so it wasn't an impossible one. For this agent, on this run, more process bought more re-reading — not more result.

Before trusting that "more structure" improved an outcome, it's worth checking whether it actually changed what came out — or just the bill.

Ever paid more for a setup that, in the end, changed nothing?
