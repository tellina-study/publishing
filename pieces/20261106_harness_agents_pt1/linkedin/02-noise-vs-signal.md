**Run the same AI coding agent on the same task twice, changing nothing. One agent came back up to 9.3× apart from itself.**

Before testing anything about rules or tools, we checked something simpler: does an agent agree with itself on a repeat run? Hermes didn't — up to 9.3× apart, same task, same settings, nothing changed. That's bigger than the loudest effect we found anywhere from switching a harness on or off (Claude Code, 4.33× on one task).

Compare two agents off a single run each — a common shortcut — and you might be ranking noise, not agents.

If you're an occasional user, this just explains why results feel inconsistent sometimes. If you're benchmarking agents for a real decision, one run isn't a benchmark.

How many runs do you actually average before trusting a coding-agent number?
